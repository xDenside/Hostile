# Licence texts that come with no package

The projects below are compiled into what Hostile ships, inside packages whose own licence files do not include
them, or ship whole beside it, so a notices file generated from the installed packages would leave them out. Their
texts are kept here.

Each has been compared with the source named below.

| File                 | Project                                   | Licence named | Source                              |
| -------------------- | ----------------------------------------- | ------------- | ----------------------------------- |
| `rnnoise.txt`        | RNNoise, inside the enhanced suppressor   | BSD-3-Clause  | github.com/xiph/rnnoise, `COPYING`  |
| `rnnoise-wasm.txt`   | `@shiguredo/rnnoise-wasm`, the same build | Apache-2.0    | github.com/shiguredo/rnnoise-wasm   |
| `fastenhancer.txt`   | FastEnhancer's model and 48 kHz weights   | MIT           | github.com/aask1357/fastenhancer    |
| `postgresql.txt`     | PostgreSQL, compiled into PGlite          | PostgreSQL    | postgresql.org/about/licence        |
| `livekit-notice.txt` | LiveKit server 1.13.7, bundled whole      | Apache-2.0    | `NOTICE` beside the Homebrew binary |
